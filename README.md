# Homebrew tap for Rewrite Better

```bash
brew tap cvthang56th2/rewrite-better
brew trust cvthang56th2/rewrite-better
brew install --cask rewrite-better
```

Upgrade later with `brew upgrade --cask rewrite-better`.

Homebrew asks you to trust this tap once because it is not an official Homebrew tap. The first open can require a right-click → Open until the app is notarized.
